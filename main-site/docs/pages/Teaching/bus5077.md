  <h2 style="color: #1f4e79; font-size: 1.4em; margin-top: 0;">Introduction</h2>
  <p>Welcome to <strong>Session 1: Introduction to Python</strong>.</p>
  <p>This session introduces the idea of coding and explains how Python fits
    into the wider family of programming languages. It begins with the role of a
    programming language, the difference between interpreted and compiled
    languages, and the meaning of high-level and general-purpose programming.
    These ideas provide the foundation for understanding what Python is doing
    when code is written and executed.</p>
  <p>The session then moves into the practical environment used throughout the
    course: <strong>Jupyter Notebooks</strong>. You will learn how notebooks
    combine explanatory text and executable Python code, why notebooks are
    useful for learning and documenting analysis, and how text cells and code
    cells support a structured workflow.</p>
  <p>The final part of this session introduces the first basic coding commands.
    You will use the <code>print</code> function to display output, create
    variables to store information, apply simple mathematical operators, and add
    comments to explain your code. This gives the session a complete progression
    from general coding concepts to writing and running your first short Python
    commands.</p>
  <p>By the end of the session, you should have a clear conceptual understanding
    of how Python code is executed and a basic practical understanding of how to
    write, run, annotate, and organise simple Python code inside a notebook.</p>
  <div
    style="background-color: #f4f8fc; border-left: 5px solid #1f4e79; padding: 16px; margin: 20px 0; border-radius: 6px;">
    <h3 style="margin-top: 0; color: #1f4e79;">Key Learning Remarks</h3>
    <ul style="margin-top: 10px; margin-bottom: 0;">
      <li>Coding is the process of writing instructions that a computer can
        execute.</li>
      <li>Python is a high-level, general-purpose and interpreted programming
        language.</li>
      <li>Interpreters and compilers provide different ways of translating
        source code into computer operations.</li>
      <li>Jupyter Notebooks combine text, code, outputs and documentation in one
        interactive environment.</li>
      <li>Text cells help explain and organise work, while code cells allow
        Python commands to be executed.</li>
      <li>The <code>print</code> function is used to display information from a
        program.</li>
      <li>Variables store information that can be reused and updated in later
        calculations.</li>
      <li>Mathematical operators allow Python to carry out basic numerical
        computations.</li>
      <li>Comments help document code and make programming work easier to
        understand and maintain.</li>
    </ul>
  </div>

  <!-- A. What is Coding? -->
  <details
    style="margin-bottom: 18px; border: 1px solid #d8e2ec; border-radius: 8px; background: #fbfdff; overflow: hidden;">
    <summary
      style="background: #edf5fc; color: #1f4e79; padding: 12px 16px; font-weight: bold; font-size: 1.15em; cursor: pointer;">
      A. What is Coding?</summary>
    <div style="padding: 16px;">
      <p>In this activity, we discuss what coding is, why it is useful, and
        introduce several core concepts that underpin modern programming
        languages. These concepts provide the foundation for understanding
        Python and how computer programs are executed.</p>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary
          style="background: #f8fafc; padding: 10px 14px; font-weight: bold; cursor: pointer; color: #34495e;">
          Programming Language</summary>
        <div style="padding: 14px;">
          <p>A programming language is a formal language consisting of syntax
            and rules that allow programmers to write instructions for a
            computer. These instructions are written as <strong>source
              code</strong> and are translated into operations performed by the
            computer. Python is one example of a programming language.</p>
        </div>
      </details>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary
          style="background: #f8fafc; padding: 10px 14px; font-weight: bold; cursor: pointer; color: #34495e;">
          Interpreted</summary>
        <div style="padding: 14px;">
          <p>Source code written in an interpreted programming language, such as
            Python, is executed directly by an <strong>interpreter</strong>. The
            interpreter reads the program line by line and executes each
            instruction immediately, without first producing a separate
            executable program.</p>
        </div>
      </details>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary
          style="background: #f8fafc; padding: 10px 14px; font-weight: bold; cursor: pointer; color: #34495e;">
          Compiled</summary>
        <div style="padding: 14px;">
          <p>Source code written in a compiled programming language is
            translated into machine code by a <strong>compiler</strong>. This
            produces an executable program that can be run directly by the
            operating system. Languages such as C and C++ are compiled, whereas
            Python is primarily interpreted.</p>
        </div>
      </details>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary
          style="background: #f8fafc; padding: 10px 14px; font-weight: bold; cursor: pointer; color: #34495e;">
          High-Level Language</summary>
        <div style="padding: 14px;">
          <p>High-level programming languages hide many of the low-level
            operations performed by a computer. This makes programs easier to
            read, write, and maintain while allowing programmers to focus on
            solving problems rather than managing hardware details.</p>
        </div>
      </details>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary
          style="background: #f8fafc; padding: 10px 14px; font-weight: bold; cursor: pointer; color: #34495e;">
          General-Purpose Language</summary>
        <div style="padding: 14px;">
          <p>A general-purpose programming language is designed to solve a broad
            range of computational problems. Rather than being limited to a
            specific application area, Python can be used for software
            development, automation, web development, data science, finance,
            artificial intelligence, and scientific computing.</p>
        </div>
      </details>
      <p style="margin-top: 18px; font-weight: bold; color: #1f4e79;">In the
        next activity, we move on to explore what Python is.</p>
    </div>
  </details>
  <!-- B. What is Python? -->
  <details
    style="margin-bottom: 18px; border: 1px solid #d8e2ec; border-radius: 8px; background: #fbfdff; overflow: hidden;">
    <summary
      style="background: #edf5fc; color: #1f4e79; padding: 12px 16px; font-weight: bold; font-size: 1.15em; cursor: pointer;">
      B. What is Python?</summary>
    <div style="padding: 16px;">
      <p>In this activity, we discuss the main properties of
        <strong>Python</strong> and consider how these properties shape its role
        within the wider family of programming languages.</p>
      <p>Python is commonly described as a <strong>high-level</strong>,
        <strong>general-purpose</strong>, and <strong>interpreted</strong>
        programming language. These features make it accessible to beginners
        while also powerful enough for professional applications in data
        analysis, finance, artificial intelligence, automation, web development,
        and scientific computing.</p>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary
          style="background: #f8fafc; padding: 10px 14px; font-weight: bold; cursor: pointer; color: #34495e;">
          High-Level</summary>
        <div style="padding: 14px;">
          <p>Python is a high-level language because it hides many of the
            technical details of how computers operate. This allows users to
            focus on solving problems and writing clear instructions rather than
            managing low-level hardware operations.</p>
        </div>
      </details>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary
          style="background: #f8fafc; padding: 10px 14px; font-weight: bold; cursor: pointer; color: #34495e;">
          General-Purpose</summary>
        <div style="padding: 14px;">
          <p>Python is general-purpose because it can be applied to many
            different tasks. It is used in areas such as data analysis, finance,
            machine learning, web development, automation, and academic
            research.</p>
        </div>
      </details>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary
          style="background: #f8fafc; padding: 10px 14px; font-weight: bold; cursor: pointer; color: #34495e;">
          Interpreted</summary>
        <div style="padding: 14px;">
          <p>Python is usually described as an interpreted language because
            Python code is executed by an interpreter. This means users can
            write and run code quickly, which is especially helpful when
            learning, testing ideas, or working interactively in environments
            such as Jupyter Notebooks.</p>
        </div>
      </details>
      <p style="margin-top: 18px; font-weight: bold; color: #1f4e79;">In the
        next activity, we will look more closely at how Python code is written
        and executed.</p>
    </div>
  </details>

      <p>The goal of this activity is to familiarise you with the

        <div style="padding: 14px;">
          <p>The Jupyter Notebook interface provides a workspace where you can
            create, edit, and organise notebooks. It includes menus, toolbars,
            and interactive cells that allow you to write code, document your
            work, and execute commands within a single environment.</p>
        </div>
      </details>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">

          Notebook Features</summary>
        <div style="padding: 14px;">
          <p>A notebook combines formatted text, executable Python code,
            graphical outputs, equations, and visualisations into a single
            document. This integrated format makes it particularly suitable for
            learning, experimentation, reproducible research, and communicating
            analytical results.</p>
        </div>
      </details>
      <details
        style="margin-top: 12px; border: 1px solid #e5e5e5; border-radius: 6px; background: white; overflow: hidden;">
        <summary

          Why Use Jupyter?</summary>
        <div style="padding: 14px;">
          <p>Jupyter Notebooks provide immediate feedback when code is executed,
