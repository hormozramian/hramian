    Introduction

    Welcome to Session 1: Introduction to Python.

    This session introduces the idea of coding and explains how Python fits into the wider family of programming languages. It begins with the role of a programming language, the difference between interpreted and compiled languages, and the meaning of high-level and general-purpose programming. These ideas provide the foundation for understanding what Python is doing when code is written and executed.

    The session then moves into the practical environment used throughout the course: Jupyter Notebooks. You will learn how notebooks combine explanatory text and executable Python code, why notebooks are useful for learning and documenting analysis, and how text cells and code cells support a structured workflow.

    The final part of this session introduces the first basic coding commands. You will use the print function to display output, create variables to store information, apply simple mathematical operators, and add comments to explain your code. This gives the session a complete progression from general coding concepts to writing and running your first short Python commands.

    By the end of the session, you should have a clear conceptual understanding of how Python code is executed and a basic practical understanding of how to write, run, annotate, and organise simple Python code inside a notebook.

    Key Learning Remarks

    • Coding is the process of writing instructions that a computer can execute.
    • Python is a high-level, general-purpose and interpreted programming language.
    • Interpreters and compilers provide different ways of translating source code into computer operations.
    • Jupyter Notebooks combine text, code, outputs and documentation in one interactive environment.
    • Text cells help explain and organise work, while code cells allow Python commands to be executed.
    • The print function is used to display information from a program.
    • Variables store information that can be reused and updated in later calculations.
    • Mathematical operators allow Python to carry out basic numerical computations.
    • Comments help document code and make programming work easier to understand and maintain.

    Datasets and Coding Notebooks

    This session introduces the Python programming environment and therefore does not require any external dataset. The accompanying coding notebook contains the examples used to practise Jupyter Notebooks, text cells, code cells, the print function, variables, mathematical operators and comments.

    Students are encouraged to modify the examples, change values, rerun cells, and observe how the output changes. This experimentation is important for building confidence with the Python workflow.

    A. What is Coding?

    In this activity, we discuss what coding is, why it is useful, and introduce several core concepts that underpin modern programming languages. These concepts provide the foundation for understanding Python and how computer programs are executed.

    Programming Language

    A programming language is a formal language consisting of syntax and rules that allow programmers to write instructions for a computer. These instructions are written as source code and are translated into operations performed by the computer. Python is one example of a programming language.

    Interpreted

    Source code written in an interpreted programming language, such as Python, is executed directly by an interpreter. The interpreter reads the program line by line and executes each instruction immediately, without first producing a separate executable program.

    Compiled

    Source code written in a compiled programming language is translated into machine code by a compiler. This produces an executable program that can be run directly by the operating system. Languages such as C and C++ are compiled, whereas Python is primarily interpreted.

    High-Level Language

    High-level programming languages hide many of the low-level operations performed by a computer. This makes programs easier to read, write, and maintain while allowing programmers to focus on solving problems rather than managing hardware details.

    General-Purpose Language

    A general-purpose programming language is designed to solve a broad range of computational problems. Rather than being limited to a specific application area, Python can be used for software development, automation, web development, data science, finance, artificial intelligence, and scientific computing.

    In the next activity, we move on to explore what Python is.

    B. What is Python?

    In this activity, we discuss the main properties of Python and consider how these properties shape its role within the wider family of programming languages.

    Python is commonly described as a high-level, general-purpose, and interpreted programming language. These features make it accessible to beginners while also powerful enough for professional applications in data analysis, finance, artificial intelligence, automation, web development, and scientific computing.

    High-Level

    Python is a high-level language because it hides many of the technical details of how computers operate. This allows users to focus on solving problems and writing clear instructions rather than managing low-level hardware operations.

    General-Purpose

    Python is general-purpose because it can be applied to many different tasks. It is used in areas such as data analysis, finance, machine learning, web development, automation, and academic research.

    Interpreted

    Python is usually described as an interpreted language because Python code is executed by an interpreter. This means users can write and run code quickly, which is especially helpful when learning, testing ideas, or working interactively in environments such as Jupyter Notebooks.

    D. Using Jupyter Notebooks: Before You Start

    This activity introduces the software tools that will be used throughout this primer. Most practical exercises will be completed using Jupyter Notebooks, an interactive environment that combines explanatory text, executable Python code, equations, and visualisations within a single document.

    By the end of this primer, you will have installed the Anaconda distribution on your computer and learned how to create, save, open, and manage Jupyter Notebooks. These skills provide the foundation for all subsequent programming activities in this course.

    What is Anaconda?

    Anaconda is a software distribution that includes Python together with many commonly used libraries for scientific computing, data analysis, machine learning, and visualisation. It also provides tools for managing programming environments and launching Jupyter Notebooks.

    What is a Jupyter Notebook?

    A Jupyter Notebook is an interactive document that combines formatted text, Python code, outputs, figures, and equations in a single file. This makes it an excellent environment for learning programming, documenting analyses, and sharing computational work.

    E. Using Jupyter Notebooks: Introduction

    The goal of this activity is to familiarise you with the Jupyter Notebook interface provided through the Anaconda distribution. You will learn how to navigate the notebook environment and understand the key features that make Jupyter an effective platform for programming, data analysis, and documentation.

    The Jupyter Interface

    The Jupyter Notebook interface provides a workspace where you can create, edit, and organise notebooks. It includes menus, toolbars, and interactive cells that allow you to write code, document your work, and execute commands within a single environment.

    Notebook Features

    A notebook combines formatted text, executable Python code, graphical outputs, equations, and visualisations into a single document. This integrated format makes it particularly suitable for learning, experimentation, reproducible research, and communicating analytical results.

    Why Use Jupyter?

    Jupyter Notebooks provide immediate feedback when code is executed, allowing users to develop programs incrementally, test ideas interactively, and document their reasoning alongside the code. This makes them widely used for Python programming in education, research, and industry.

    In the next activity, we continue exploring Jupyter Notebooks and learn how to create, edit, and execute notebook cells.

    F. Jupyter Notebooks: Cells and Executing Code

    In this activity, we explore one of the key features of Jupyter Notebooks: the use of cells. Notebooks are organised into individual cells, allowing you to combine explanatory text with executable Python code within a single interactive document.

    Text Cells / Markdown Cells

    Text cells, also known as Markdown cells, are used to document your work. They can contain formatted text, headings, bullet points, hyperlinks, tables, mathematical equations, and images. These cells help explain the purpose of your code and make notebooks easier to read and share.

    Code Cells

    Code cells contain Python commands that can be executed by the notebook's Python kernel. When a code cell is run, the output, such as text, tables, figures, or error messages, is displayed immediately below the cell, providing instant feedback.

    Executing Code

    A code cell can be executed by selecting it and pressing Shift + Enter, or by clicking the Run button on the toolbar. Executing a cell sends its contents to the Python interpreter, which processes the commands and returns the corresponding output.

    Why Cells Are Useful

    The cell-based structure allows programs to be developed incrementally. You can edit and rerun individual sections of code without executing the entire notebook, making experimentation, debugging, and documentation much more efficient.

    In the next activity, we will continue exploring Jupyter Notebooks and learn how to manage notebook outputs and variables.

    G. Jupyter Notebooks: Text Cells

    In this activity, we explore Markdown cells, also known as text cells. These cells allow you to add explanations, headings, notes, equations, and other documentation alongside your Python code, making notebooks easier to understand and share.

    What is a Markdown Cell?

    A Markdown cell is used to write formatted text rather than executable Python code. It enables you to describe your analysis, provide instructions, document results, and organise your notebook into clearly defined sections.

    Formatting Features

    Markdown supports a variety of formatting options, including headings, bold and italic text, bullet and numbered lists, hyperlinks, tables, images, block quotations, and mathematical equations. These features help create well-structured and professional notebooks.

    Why Use Text Cells?

    Text cells improve the readability and organisation of a notebook by documenting the purpose of each section of code, explaining methods and assumptions, and interpreting results. They are an important component of reproducible research and collaborative programming.

    Editing Markdown Cells

    A Markdown cell can be edited like any text document. Once the content has been written, pressing Shift + Enter renders the formatted output, allowing you to view the document as it will appear in the notebook.

    I. The Print Statement

    In this activity, we begin to explore the use of the print statement. The print statement is a useful and important function in Python because it allows us to extract information from our code and display it on the screen.

    This is useful for creating outputs, checking whether code is working correctly, debugging errors, and providing information to a user.

    What does print do?

    The print function sends information from a Python program to the output area. In a Jupyter Notebook, this output is displayed directly below the code cell after the cell is run.

    Why is print useful?

    The print function is often used when learning Python because it gives immediate feedback. It can show the result of a calculation, display the value of a variable, or help identify where an error may be occurring.

    J. Setting Variables

    In this activity, we explore variables. A key concept in any coding language is that of a variable. When data is saved in a program, it is referred to as a variable and may be referenced by one or more variable names.

    These variable names allow us to access, alter, or use the stored data in calculations. Variables are therefore central to writing useful programs because they allow information to be stored and reused.

    What is a Variable?

    A variable is a named location used to store data in a program. Once a value has been assigned to a variable, the variable name can be used later in the code to refer back to that value.

    Why Variables Matter

    Variables make code more flexible and easier to understand. Instead of repeating values throughout a program, you can store a value once and refer to it by name whenever it is needed.

    K. Mathematical Operators

    In this activity, we look at how to use some basic mathematical operators in Python. Many of these operators work in a similar way to how you would expect them to work in a mathematical equation.

    Mathematical operators allow Python to perform calculations, making them one of the most important tools for solving numerical problems in code.

    Common Operators

    Python includes operators for common calculations such as addition, subtraction, multiplication, division, powers, and other mathematical operations. These operators can be used directly with numbers or with variables that store numerical values.

    Operators and Variables

    Once a number has been stored in a variable, the variable name can be used inside a mathematical expression. This makes it possible to write calculations that are easier to update and reuse.

    L. Comments

    In this activity, we look at how to use comments. Comments are common to many coding languages and provide a way to write notes in a source file that will be ignored by the interpreter.

    Comments are useful because they allow you to explain what your code is doing, record your thinking, and make programs easier for other people to understand.

    What is a Comment?

    A comment is text written inside a source file that is intended for human readers rather than the computer. When Python runs the program, comments are ignored and do not affect the output.

    Why Comments are Useful

    Comments help explain the purpose of code, document assumptions, clarify complex sections, and make your work easier to revisit later. They are especially valuable when code is shared with other users.

    Good Practice

    Good comments should be clear, concise, and useful. They should explain why something is being done or clarify the purpose of a section of code, rather than simply repeating what is already obvious.

    Main Python Commands and Syntax
    Command / Syntax Purpose
    print() Displays output on the screen.
    = Assigns a value to a variable.
    # Adds a comment ignored by Python.
    + - * / Performs addition, subtraction, multiplication and division.
    ** Raises a number to a power.
    % Returns the remainder after division.
    // Performs floor division.
    () Calls functions or controls the order of operations.
    'text' or "text" Creates a string value.
    Compact Python Examples 
    # Display output
print("Hello World")

# Store values in variables
x = 10
y = 20

# Use variables in calculations
total = x + y
print(total)

# Apply mathematical operators
price = 125
tax = 0.20
final_price = price * (1 + tax)
print(final_price)

# Use powers
radius = 5
area = 3.14159 * radius ** 2
print(area)

# Add comments to explain code
# This line calculates a simple portfolio return
portfolio_return = 0.08
print(portfolio_return)
